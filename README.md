# 摇篮计划（Project Cradle）

> 摇篮：定义一套让系统经由类婴儿发育长出智能的完整思想方案。

**立项日期**：2026-08-20
**项目形态**：大文档库——只有文档、图、伪代码，**不会有任何具体实现**。
**思想来源**：与智谱清言（ChatGLM5）的会话推导，起点是对现有方向的分析，见 [00-起源.md](00-起源.md)。

## 一句话立论

> 智能不是一种可以被灌输的状态，而是一种必须被经历的过程。
> 当前主流的做法，是拿着成体图，想跳过发育，直接 3D 打印一个成年人。

摇篮计划不造更聪明的成品，而是定义一套**让系统经由发育长出智能的完整条件**（起点不是"无"，是只有物种级先验的空架构）——核心思想是**借鉴人类大脑机制、模拟人类发育过程**：三条公理（经验不可替代、发展有时序、环境是唯一的老师）、七个核心概念（权重继承、最近的坡、预测误差是唯一的学习信号、动机的生态、敏感期、反事实引擎、社会回路）、六个发育阶段（先验→身体→客体→符号→想象→文化）；每个概念的生物学依据见 [10-发育机制与发育周期.md](10-发育机制与发育周期.md)。

## 核心立场

- 摇篮不装大人，只装婴儿——成长判据是**发育事件**（第一次为看不见的东西去够、第一次被纠错后修正信号），不是 benchmark。
- 毕业的定义只有一条：**系统开始给自己排课**（显式的自我指向，区别于自出生即运转的隐式夹逼课程）。摇篮对个体的意义是有一天不再需要它；对这条链的意义是永远有下一个摇篮要摇。
- 发育按序发生：经历由系统亲身获得、按序积累，不可并行、不可置换——摇篮定义的是这条序，不是任何可度量的产出。
- 本计划不以意识为目标；诚实的立场是"不知道"。
