摇篮计划（/code/ai/yaolan）于 2026-08-20 立项，源自用户与智谱清言（ChatGLM5）的会话推导（分享链接 chatglm.cn/share/oFmdgtMI）。

**Why:** 立项决策由用户明确：项目是大文档库——只有文档、图、伪代码，**不会有任何具体实现**；文档平铺根目录不用子目录；起源文档只写现有方向的客观分析，不拉踩其它理论。

**How to apply:** 本仓库永不写实现代码/框架选型；修改思想文档（20-思想文档.md）必须递增版本号且禁止重写式改写（其第六章第 4 条自我规定）；「摇篮」指发育图路线（智能是长出来的），与 BAAI 的 Cradle agent 框架无关。
